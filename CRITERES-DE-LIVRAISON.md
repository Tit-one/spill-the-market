# Critères de livraison proposés

Date : 7 novembre 2026. Statut : plan en attente de validation, aucune réalisation validée.

Référence : [PLAN-A-VALIDER.md](PLAN-A-VALIDER.md).

## Première version

- [ ] Installation propre Windows/Linux/macOS, application locale, interface embarquée, CLI et API partageant les services.
- [ ] Démonstration des quatre modules, données fictives et réseau désactivé.
- [ ] Trois modes de recherche : API, URL/RSS choisis, imports hors ligne ; sources/extraits/dates/couverture/erreurs conservés.
- [ ] Sorties JSON versionnées ; faits, déductions et hypothèses distingués ; pas de croissance historique ni de démographie inventée.
- [ ] Âges stricts et diversité au sein d'une tranche ; mémoire locale et isolation des expériences.
- [ ] Catalogue de canaux demandé présent avec mécanismes réellement exécutés, coûts et plafonds fonctionnels.
- [ ] Courtes vidéos, groupes fermés et publicités dans les jeux possèdent des comportements distincts.
- [ ] Plans adaptés au produit, éditables/verrouillables ; fréquence, récence, fatigue et saturation affectent les résultats.
- [ ] Calendrier exécuté une seule fois, même après reprise.
- [ ] Intention conditionnelle séparée des achats ; acquisitions dédupliquées, identité commune entre canaux.
- [ ] Trois stratégies, mêmes conditions initiales, budgets comparables et témoins pertinents.
- [ ] CA, dépenses, commissions, conversions attribuées et CAC rapprochés avec les traces ; ratios sans dénominateur explicites.
- [ ] Exploration et validation distinctes ; versions, paramètres, sources et graines sauvegardés.
- [ ] Budgets réels contrôlés entre recherche, génération, rapports, concurrence, réessais et reprise.
- [ ] Réservations incertaines conservées après incident ; aucune relance facturable aveugle.
- [ ] Annulation/reprise vérifiées ; résultats engagés équivalents à une exécution continue.
- [ ] Benchmarks 1 000/10 000/100 000 personnes puis étude complète, avec temps/RAM/disque/appels/matériel documentés.
- [ ] URL et redirections contrôlées, entrées traitées comme données, HTML assaini, secrets exclus des sorties publiques.
- [ ] MiroFish existant préservé ; imports et connecteur mémoire optionnel vérifiés séparément.
- [ ] Documentation anglaise/française, exemples, méthodologie, contribution, notices et exports présents.
