# Launch notebook

Approved visual direction, implemented in Operate mode. An entrepreneur works at a desk in daylight; light content surfaces support prolonged reading, saturated blue carries navigation and the active experiment.

Palette: experiment blue #214cfa, ink #14213d, paper #ffffff, canvas #f3f5f9, line #dce2ec, secondary ink #56627a. Semantic green #176344, amber #87500a, red #b12937. Blue is reserved for identity, selection, primary action, and real run progress.

System UI sans for all interface text, Segoe UI at the Windows boundary. Headings are compact, moderately bold and tight; tabular numerals carry measurement. No remote requests for typography or imagery.

The signature is an experiment spine: a narrow blue navigation rail, a large brief worksheet, and a compact campaign timeline that becomes the run monitor. Genuine ordered steps use numbers. Working surfaces have generous gutters and quiet horizontal rules, not repeating icon cards. Native inputs are consistently shaped with visible labels, a 7px control radius, and a 3px focus outline. Navigation items remain visibly labelled.

The rail collapses to a horizontal workflow on narrow screens. Data tables scroll in a labelled region. Forms use two columns where useful and one on mobile. Interactive targets reach 40px. Hover/focus/disabled/error/busy states are explicit. Reduced motion disables progress animation. Charts use SVG only for actual data; Phosphor supplies interface icons.
