# Home and report surfaces

Mode: Operate. Audience: creators describing a product and evaluating a launch experiment.

The replacement follows the installed MiroFish visual grammar: white, black, orange, horizontal masthead, a quiet workflow column, and a decisive input console. Home makes the next action obvious without preloading a fictional product. Saved experiments remain easy to reopen.

The report answers first: what happened, which strategy led, how many virtual units sold, what revenue/spend/CAC resulted, and why the result needs caution. Conditional averages belong to a named scenario, never a sum of alternatives.

Page analysis summarizes primary findings and sampled persona questions by age before individual reviews, DOM, receipts and diagnostics. Language switching, mobile/keyboard operation, local capture, explicit remote consent and exports remain intact.

Reference files were inspected read-only. No reference code or visual assets are copied. Direction selection is settled by the user's explicit instruction; no new concept tournament or approval is required.
